# S4 — Secure Exam Runner, Autosave, Timer, Resume

**Goal:** Make exam-taking robust against reload, poor connectivity and concurrency.

**Enabled FRs:** FR-22, FR-23, FR-24, FR-25, FR-26, FR-27

## Implement (backend + frontend + tests)
- Migrate attempts, attempt_questions, attempt_options, answers, marks, expiry metadata; atomic start with one active attempt.
- Backend authoritative deadline and `spark` command to finalize expired; 403/409 on invalid saves; transaction locks.
- Versioned autosave endpoints; idempotency for retries; frontend debounced per-question queue with saving/saved/error states.
- Exact stable resume of question and option orders, answers, marks, deadline after refresh/re-login.
- Runner React desktop right palette/mobile Sheet, accessible timer, mark-for-review, confirm submit with unanswered count.
- Submit idempotent, auto-finalize expired attempts even offline; no unverified local success.

## Acceptance gate — MUST pass
- [ ] ATT-01..06 pass, including out-of-order request/concurrent double submit/expired offline cleanup.
- [ ] Responsive runner at 320px, 390px, 1280px and keyboard navigation; npm build passes.
