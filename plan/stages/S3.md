# S3 — Exam Builder, Publishing, Assignments & Policies

**Goal:** Produce publishable school exams with immutable snapshot.

**Enabled FRs:** FR-13, FR-14, FR-15, FR-16, FR-17, FR-18

## Implement (backend + frontend + tests)
- Migrate exams, exam_classes, exam_assignments, exam_items(snapshot), attempt policy fields, status machine.
- Build exam wizard + backend validation for schedule, duration, passing grade, target rombel, participants, questions and weights.
- Implement teacher publish policy: teacher must manage exam AND have active mapel assignment for ALL targeted classes; school admin may publish within school.
- Snapshot question/options/keys on publish and explicit roster assignment; retain immutable published version.
- Implement start-policy race constraints/max_attempts foundation and deterministic shuffle algorithm persisted at attempt start.
- Student sees only assigned exam list/instructions, no frozen answer keys.
