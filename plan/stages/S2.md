# S2 — Question Bank (MCQ + Images)

**Goal:** Deliver secure reusable author-scoped question bank.

**Enabled FRs:** FR-07, FR-08

## Implement (backend + frontend + tests)
- Migrate questions, options, assets with topic/subject/school/author FK; soft delete where referenced.
- REST CRUD, valid MCQ min 2 exactly one correct on publish, score weight, optional explanation; draft allowed.
- Private upload storage with MIME, max bytes, file magic checks and authorized serving; strip HTML scripts.
- React question editor, image/file controls, preview responsive, question list filters and permission checks.
- Guard against student reading keys via serializers and unauthorized assets.

## Acceptance gate — MUST pass
- [ ] QST-01..03 pass; sample valid question previews correctly and image loads only when authorized.
- [ ] All question content mobile-safe and can be used by exam builder.

Question revisions are S7; freeze later in S3. Do not expose is_correct in any student-readable API.
